# 夸克网盘

夸克网盘容量成长签到，每日签到领取空间奖励。

### 配置示例

```json filename="config.json" copy
{
  "QUARK": [
    {
      "cookie": "夸克网盘网页版 Cookie"
    }
  ]
}
```

|        参数        |                     说明                      |
| :----------------: | :-------------------------------------------: |
| _**QUARK**_.cookie | 登录 [夸克网盘](https://pan.quark.cn/) 网页版后，从请求中复制的完整 Cookie |
