# 小米运动

### 配置示例

```json filename="config.json" copy
{
  "MIMOTION": [
    {
      "max_step": "20000",
      "min_step": "10000",
      "password": "Sitoi",
      "phone": "18888xxxxxx"
    },
    {
      "max_step": "多账号 最大步数填写，请参考上面",
      "min_step": "多账号 最小步数填写，请参考上面",
      "password": "多账号 密码填写，请参考上面",
      "phone": "多账号 手机号填写，请参考上面"
    }
  ]
}
```

### 配置说明

|          参数           |                说明                |
| :---------------------: | :--------------------------------: |
|  _**MIMOTION**_.phone   | 小米运动刷步数的「手机」或「邮箱」 |
| _**MIMOTION**_.password |      小米运动刷步数的账号密码      |
| _**MIMOTION**_.min_step |      小米运动刷步数的最小步数      |
| _**MIMOTION**_.max_step |      小米运动刷步数的最大步数      |
| _**MIMOTION**_.app_token |   登录凭证（可选），可留空    |
| _**MIMOTION**_.user_id  |      用户 ID（可选），可留空       |

<Callout type="info">
  `app_token` 与 `user_id` 均为可选字段，留空即可：首次运行登录成功后会自动把这两个字段写回
  `config.json`，之后每次运行直接复用凭证提交步数，不再反复登录，避开小米运动登录接口的频率限制；
  凭证失效时会自动重新登录并更新写回。
</Callout>
