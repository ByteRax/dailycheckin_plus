# 小牛电动

社区分享任务：登录小牛电动开放平台，自动分享社区帖子获取积分。

### 配置示例

```json filename="config.json" copy
{
  "NIU": [
    {
      "account": "18888xxxxxx",
      "password": "登录密码的 MD5 小写值"
    }
  ]
}
```

|        参数        |                                            说明                                             |
| :----------------: | :-----------------------------------------------------------------------------------------: |
|  _**NIU**_.account  |                             小牛电动 APP 登录账号（手机号）                             |
| _**NIU**_.password |                    登录密码的 **MD5 小写值**（接口按小写校验）                     |
| _**NIU**_.app_id   |                          可选，默认内置 APP ID `niu_ktdrr960`                          |
| _**NIU**_.state_file |              可选，token 缓存文件路径，默认 `~/.dailycheckin/niu_token.json`              |

登录 token 会持久化到本地并在过期前自动刷新，避免频繁登录。
