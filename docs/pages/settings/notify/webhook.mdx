# 自定义 Webhook

<Callout type="info">
  通用 webhook 渠道，可以接入 MeoW、Synology Chat 等任意接收 JSON 或 query 参数的通知服务，没有专属渠道时优先用它。
</Callout>

### 配置示例

```json filename="config.json" copy
{
  "WEBHOOK_URL": "",
  "WEBHOOK_METHOD": "POST",
  "WEBHOOK_BODY": "{\"title\": \"{title}\", \"content\": \"{content}\"}",
  "MERGE_PUSH": ""
}
```

|        参数         |                                                     说明                                                     |
| :-----------------: | :---------------------------------------------------------------------------------------------------------: |
| _**WEBHOOK_URL**_  |                自定义 webhook 推送地址，填写 `WEBHOOK_URL` 例: `https://example.com/webhook`                 |
| _**WEBHOOK_METHOD**_ |       请求方法 `POST` 或 `GET`，默认 `POST`；`GET` 时标题与内容以 `title` / `content` query 参数发送        |
| _**WEBHOOK_BODY**_ | `POST` 请求体的 JSON 模板，支持 `{title}` `{content}` 占位符；内容中的引号、换行会自动转义，`GET` 时忽略该参数 |
|   _**MERGE_PUSH**_  |                              **true**: 将推送消息合并；**false**: 分开推送                                  |

<Callout type="warning" emoji="⚠️">
  `WEBHOOK_BODY` 渲染占位符后必须是合法 JSON，模板写错时该次推送不发送；响应非 2xx 状态码视为推送失败。
</Callout>
