# WPUSH

### 配置示例

```json filename="config.json" copy
{
  "WPUSH_APIKEY": "",
  "WPUSH_CHANNEL": "",
  "WPUSH_TOPIC_CODE": "",
  "MERGE_PUSH": ""
}
```

|         参数          |                          说明                           |
| :-------------------: | :-----------------------------------------------------: |
|   _**WPUSH_APIKEY**_   | [WPUSH](https://wpush.cn/) 用户 API Key，填写 `WPUSH_APIKEY` |
|   _**WPUSH_CHANNEL**_  |      推送渠道，不填默认 `wechat`，例如: `wechat`        |
| _**WPUSH_TOPIC_CODE**_ |             Topic 广播编码，非必填，不填不发送             |
|   _**MERGE_PUSH**_    |     **true**: 将推送消息合并；**false**: 分开推送      |
