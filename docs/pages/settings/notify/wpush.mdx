# WPUSH

### 配置示例

```json filename="config.json" copy
{
  "WPUSH_APIKEY": "",
  "WPUSH_CHANNEL": "",
  "WPUSH_TOPIC_CODE": "",
  "MERGE_PUSH": ""
}
```

|         参数         |                                        说明                                        |
| :------------------: | :--------------------------------------------------------------------------------: |
|  _**WPUSH_APIKEY**_  | [WPUSH](https://wpush.cn/) 推送，填写个人中心获取的 `apikey`，必填才会启用该通道 |
| _**WPUSH_CHANNEL**_  |              可选，推送渠道，默认 `wechat`（微信服务号）              |
| _**WPUSH_TOPIC_CODE**_  |              可选，群发/主题 code，不填则单推              |
|   _**MERGE_PUSH**_   |                   **true**: 将推送消息合并；**false**: 分开推送                    |
