# WXPUSHER

### 配置示例

```json filename="config.json" copy
{
  "WXPUSHER_TK": "",
  "WXPUSHER_UID": "",
  "MERGE_PUSH": ""
}
```

|         参数        |                                        说明                                         |
| :-----------------: | :---------------------------------------------------------------------------------: |
|  _**WXPUSHER_TK**_  | [WXPUSHER](https://wxpusher.zjiecode.com/) 的 `appToken`，创建应用后获取 |
| _**WXPUSHER_UID**_  |          关注应用后获得的用户 `UID`（形如 `UID_xxxx`）          |
|  _**MERGE_PUSH**_   |                    **true**: 将推送消息合并；**false**: 分开推送                     |
