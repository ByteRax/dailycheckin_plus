## 新增与补齐的通知参数

以下通知参数为本 fork 相对上游 README 模板新增或补齐的键（上游代码已支持但模板缺失的也已补上），含义如下：

| 参数 | 说明 |
| :--- | :--- |
| _**BARK_GROUP**_ | bark 消息分组（可选，例如: `DailyCheckin`） |
| _**BARK_ICON**_ | bark 推送图标 URL（可选） |
| _**BARK_SOUND**_ | bark 推送提示音（可选，如 bell、alarm） |
| _**QMSG_URL**_ | qmsg 推送 API 地址，私有部署时填写，默认 `https://qmsg.zendee.cn` |
| _**QMSG_QQ**_ | 指定接收消息的 QQ 号，多个用英文逗号分隔（可选） |
| _**QMSG_BOT**_ | qmsg 机器人的 QQ 号（可选） |
| _**GOTIFY_URL**_ / _**GOTIFY_TOKEN**_ / _**GOTIFY_PRIORITY**_ | gotify 服务地址 / 应用 token / 推送优先级 |
| _**NTFY_URL**_ / _**NTFY_TOPIC**_ / _**NTFY_PRIORITY**_ | ntfy 服务地址 / 推送主题 / 推送优先级 |
| _**QYWX_ORIGIN**_ | 企业微信应用反向代理地址，替换默认的 `https://qyapi.weixin.qq.com` |
| _**WPUSH_APIKEY**_ | WPUSH 用户 API Key（wpush.cn） |
| _**WPUSH_CHANNEL**_ | WPUSH 推送渠道，不填默认 `wechat` |
| _**WPUSH_TOPIC_CODE**_ | WPUSH Topic 广播编码（可选） |
| _**XXTUI_KEY**_ | xxtui 推送 Key（xxtui.com） |
| _**WEBHOOK_URL**_ | 自定义 Webhook 推送地址，可接入 MeoW、Synology Chat 等任意 webhook 服务 |
| _**WEBHOOK_METHOD**_ | Webhook 请求方法 `POST` / `GET`，默认 `POST`；`GET` 时 `title` / `content` 走 query 参数 |
| _**WEBHOOK_BODY**_ | Webhook `POST` 请求体的 JSON 模板，支持 `{title}` `{content}` 占位符 |
| _**PUSHME_KEY**_ | PushMe 推送 Key（push.i-i.me） |
| _**QLAPI**_ | 青龙 QLAPI 通知桥开关，非空即启用（建议填 `true`），仅青龙环境生效 |
| _**SMTP_SERVER**_ | SMTP 邮件服务器地址 |
| _**SMTP_PORT**_ | SMTP 端口，默认 `465`；`465` 走 SSL，`587` 等走 STARTTLS |
| _**SMTP_SSL**_ | 强制指定是否 SSL（`true` / `false`），留空按端口自动选择 |
| _**SMTP_USER**_ | SMTP 发件账号（登录用户名） |
| _**SMTP_PASSWORD**_ | SMTP 登录密码或授权码 |
| _**SMTP_TO**_ | 收件人地址，多个用英文逗号分隔，留空发给发件账号 |
| _**PUSHDEER_PUSHKEY**_ | PushDeer 推送 Key（pushdeer.com） |
| _**WXPUSHER_APPTOKEN**_ | wxPusher 应用 appToken（wxpusher.zjiecode.com） |
| _**WXPUSHER_UIDS**_ | wxPusher 用户 UID，多个用英文逗号分隔 |

<Callout
  type="warning"
  emoji="⚠️"
>
  模板中 `BARK_GROUP`、`BARK_ICON`、`QMSG_QQ`、`QMSG_BOT`、`QMSG_URL` 等键的值为示例占位文本，不使用请清空为 `""`，避免占位文本被当作有效值发送。
</Callout>
