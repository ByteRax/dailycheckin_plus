- 通知：Server酱³ 支持（SCKEY/SENDKEY 按前缀路由，Refs: Sitoi/dailycheckin#517）；bark 提示音与超长分批（Refs: #320 #387 #523）
- 安全：6 处凭据传输改 https、6 处移除 verify=False（探测证据见 .maintenance 任务 T-A05d）
- 验证：Python 3.9 实测 200 项测试全过；docs 站 next build 真实构建通过

> 以下变更来自 fork [ByteRax/dailycheckin_plus](https://github.com/ByteRax/dailycheckin_plus) 的集成分支，基于上游 v25.12.9，尚未发布正式版本。编号均指上游 Sitoi/dailycheckin 的 Issue / PR。

### ✨ 功能

- 新增「WPUSH」通知渠道（吸收 #590）
- 新增「xxtui」通知渠道（吸收 #564）
- 新增「自定义 Webhook」通知渠道，支持 `WEBHOOK_METHOD`（POST/GET）与 `WEBHOOK_BODY` JSON 模板占位符（吸收 #578，可覆盖 MeoW #547、Synology Chat #403 场景）
- 新增「PushMe」通知渠道（吸收 #435）
- 新增「青龙 QLAPI」通知桥，复用青龙面板已配置的通知渠道，仅青龙环境生效（吸收 #573）
- 新增「SMTP」邮件通知渠道，465 SSL / 587 STARTTLS 自动选择（吸收 #579）
- 新增「PushDeer」通知渠道（吸收 #558，重实现 #366）
- 新增「wxPusher」通知渠道（重实现 #366）
- 「qmsg 酱」支持 `QMSG_QQ` / `QMSG_BOT` 参数与 `QMSG_URL` 私有部署地址（吸收 #566 #453）
- 「Bark」支持 `BARK_GROUP` / `BARK_ICON` 参数，并修复 URL 带 query 时被顶坏的拼接缺陷（吸收 #387 #523，重实现 #320 的 group/icon 部分）
- CLI 新增 `--accounts "1,3-5"` 按账号序号执行部分账号（重实现 #544，参考 #533 #565）
- `--include` / `--exclude` 服务名大小写不敏感，未知服务名输出警告与可用服务列表
- 补齐模板中缺失的通知键：`QYWX_ORIGIN`、`GOTIFY_URL/TOKEN/PRIORITY`、`NTFY_URL/TOPIC/PRIORITY`
- 模板新增第二批 14 个通知键：`WEBHOOK_URL/METHOD/BODY`、`PUSHME_KEY`、`QLAPI`、`SMTP_SERVER/PORT/SSL/USER/PASSWORD/TO`、`PUSHDEER_PUSHKEY`、`WXPUSHER_APPTOKEN/WXPUSHER_UIDS`

### 🐛 修复

- 修复「BiliBili」区域任务接口失效与 cookie 失效时的假成功（#588 #586 #585 #515）
- 修复「恩山无线论坛」WAF 521 拦截与积分页裸异常（融合 #562 #572 #557，参考 #569 #501）
- 「百度网盘」签到成功后自动原子回写续期 cookie 到 `config.json`，只读挂载场景跳过并警告（#591 采纳并加固，参考 #534 #577）
- 修复「什么值得买」奖励信息三种返回状态解析（#479 #571 #523）
- 修复「V2EX」签到链接缺失时静默失败的问题（#525）
- 修复「百度贴吧」签到接口失效（#509）
- 修复「飞牛 NAS」登录失效后无提示的问题（#589）
- 修复「i 茅台」门店列表接口 404 与接口失败时的假成功（#563 #568）
- 「小米运动」登录成功后自动保存并复用 `app_token` / `user_id`（可选字段，首跑自动写回 `config.json`），避免每次运行都登录触发接口频率限制（#533 #565）
- 修复任务无返回结果时被误报为签到成功的问题
- `datetime.utcnow` 替换为时区感知写法，消除 Python 3.12+ 弃用告警

### 🔧 部署

- Docker 镜像迁移至 `ghcr.io/byterax/dailycheckin_plus`（amd64 + arm64），由源码构建；基础镜像换为 `python:3.11-slim`（Python 版本要求仍为 3.9+）
- 镜像与部署脚本不再从 PyPI 自动升级，升级方式为拉取新镜像或重新源码安装
- Release 工作流只构建 sdist + wheel 并附着在 GitHub Release，不再发布 PyPI
