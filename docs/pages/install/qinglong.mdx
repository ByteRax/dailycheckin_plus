# 青龙使用教程

## 一、安装

<Steps>
### 选择「依赖管理」

![点击依赖管理](../img/qinglong/1.png)

### 新建 Linux 依赖

#### 1. 点击 Linux

![点击 Linux](../img/qinglong/2.png)

#### 2. 点击新建依赖

![点击新建依赖](../img/qinglong/3.png)

#### 3. 输入依赖

```text copy
gcc g++ make libffi-dev libssl-dev
```

<Callout type="info">
  `libssl-dev` 适用于 Debian / Ubuntu 系镜像；CentOS / RHEL 系请改用 `openssl-devel`。旧的 `openssl-dev` 包名在常见发行版中不存在，会导致依赖安装失败。
</Callout>

![输入依赖](../img/qinglong/4.png)

#### 4. 点击确认，等待安装完成

![点击确认](../img/qinglong/5.png)

### 安装 Python 依赖（源码安装本 fork）

<Callout
  type="warning"
  emoji="⚠️"
>
  PyPI 上的 `dailycheckin` 包属于上游项目，请勿直接按包名安装；本 fork 需从源码安装（青龙镜像自带 git）。
</Callout>

在「在线终端」执行（或新建一个定时任务，命令填写如下内容后手动运行一次）：

```bash copy
pip3 install "dailycheckin @ git+https://github.com/ByteRax/dailycheckin_plus@main"
```

安装完成可通过 `pip3 show dailycheckin` 确认版本信息中 `Project-URL` 指向本 fork 仓库。

</Steps>

## 二、配置

</Callout>

### 输入文件名 config.json 后确定

![输入文件名](../img/qinglong/12.png)

### 配置 config.json 文件

参考[配置说明文档](/settings/config) ，并修改 `config.json`

![编辑配置](../img/qinglong/13.png)
![配置示例](../img/qinglong/14.png)

</Steps>

## 三、运行

1. 运行全部脚本
   ![定时任务](../img/qinglong/15.png)
2. 运行指定脚本（包含），可以同时选择多个，用「空格」分开
   ![定时任务](../img/qinglong/16.png)
3. 运行指定脚本（排除），可以同时选择多个，用「空格」分开
   ![定时任务](../img/qinglong/17.png)

## 四、更新

添加一个定时任务，名称为 更新Dailycheckin（可自定义），命令为 `task pip3 install "dailycheckin @ git+https://github.com/ByteRax/dailycheckin_plus@main" --upgrade`，定时规则为 0 0 * * *。

本 fork 从 git 源码安装，不走 PyPI 镜像；国内机器如拉取 GitHub 慢，可为 git 配置代理或使用镜像加速后重试。

![定时更新](../img/qinglong/18.png)
